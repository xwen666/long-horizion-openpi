# Grasp Utilities

These scripts are legacy, hardware-specific utilities for the local Piper
grasp experiments. They are kept separate from the reusable LIBERO/Cosmos
tools because they reference external Piper SDK and dataset paths.

The reusable WorldPilot/Cosmos tools are in the parent `tools/` directory:

- `build_cosmos_latent_cache.py`
- `compare_worldpilot_cache_realtime.py`
- `cosmos_realtime_worker.py`
